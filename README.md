# Roblox Duplicate

Англоязычная витрина с мини-окном проверки членства. Статический сайт готов к размещению. Сборка и установка зависимостей не требуются.

## Где поменять ссылки

Открой [dist/config.js](dist/config.js) и заполни значения между кавычками.

| Поле | Что вставить | Где появится |
| --- | --- | --- |
| `groupUrl` | Полный HTTPS-адрес своего сообщества на roblox.com | На заметной кнопке **Open group on Roblox**. Ниже отображается адрес назначения |
| `verificationPage` | Путь к своей странице проверки на том же сайте, например `./verification/index.html` | Внутри мини-окна на главной |

Для указанного примера положи файл интерфейса в `dist/verification/index.html`. Серверная часть твоей проверки должна быть доступна этому интерфейсу. Пустые поля оставляют сайт в режиме предпросмотра.

## Просмотр и размещение

Для просмотра главной открой `dist/index.html`. Чтобы проверить встроенную страницу, запусти HTTP-сервер из каталога `dist`. После размещения добавь `#verify` к адресу главной, чтобы открыть мини-окно по прямой ссылке.

При загрузке исходников в GitHub сохрани файлы `.openai/hosting.json` и `dist/index.html` на указанных путях. Манифест содержит ID текущего проекта Sites и задаёт `dist` как папку публикации. Для другого статического хостинга достаточно разместить содержимое `dist` в корне сайта.
